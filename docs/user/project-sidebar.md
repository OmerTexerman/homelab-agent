# Projects in the sidebar

The sidebar lists your threads under the project they belong to. The project
you worked in most recently comes first. **Scratch** threads, which run outside
any project, sit in their own group at the bottom.

Each project header shows:

- a dot for the project's runtime: green while it is running or awake, grey
  while it is sleeping or not started yet, and red if it failed. Hover the dot
  to read the state.
- the project name. Select it to open the project's page.
- how many active threads the project has.
- **+**, which starts a new thread in that project. In the Scratch group it
  starts a new scratch thread.

Select the arrow before a project's name to collapse or expand its group. The
app remembers which groups you collapsed. The thread you have open stays
visible even inside a collapsed group.

Pinned threads stay at the top of the sidebar, above the project groups. The
**Snoozed** and **Settled** shelves stay at the bottom and hold parked threads
from every project. Dragging works as before: drag a thread to pin, settle, or
wake it. While you drag, the project headers step aside so the list shows
where the thread will land.

## Search and filter

Typing in the search box lists matching threads under the project they belong
to. Projects with no match are hidden.

The folder button next to the search box shows a single project. With one
project selected, only that project's group appears.

## Add a project

The **New project** button in the sidebar header is always available, including
before you have any projects.
